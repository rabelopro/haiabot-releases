# HaiaBot

Instaladores do HaiaBot para Mac, o copiloto jurídico de audiências.

- Mac com Apple Silicon (M1, M2, M3, M4): [HaiaBot-arm64.dmg](https://github.com/rabelopro/haiabot-releases/releases/latest/download/HaiaBot-arm64.dmg)
- Mac com Intel: [HaiaBot-x64.dmg](https://github.com/rabelopro/haiabot-releases/releases/latest/download/HaiaBot-x64.dmg)

Os links acima sempre baixam a versão mais nova. O app instalado se atualiza sozinho.
Assinado com o Developer ID e notarizado pela Apple. Requer macOS 14.2 ou mais novo.
